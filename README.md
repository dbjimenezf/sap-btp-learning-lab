# SAP BTP Learning Lab

**Hands-on learning laboratory focused on SAP Business Technology Platform, SAP HANA Cloud and enterprise application development.**

## Overview

This repository documents my practical learning journey within the SAP ecosystem.

The main objective is to develop technical skills through hands-on exercises, guided tutorials, experimentation and independent projects.

The laboratory focuses on cloud technologies, database management, backend development and enterprise application integration.

## Learning Objectives

- Understand SAP Business Technology Platform (BTP).
- Explore SAP HANA Cloud and database administration.
- Develop programming skills using ABAP.
- Learn SAP Fiori and enterprise application development.
- Understand cloud services, integrations and security.
- Build and document practical SAP-based projects.
