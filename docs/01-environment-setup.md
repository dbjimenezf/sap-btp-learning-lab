# SAP BTP Trial – Environment Setup

## 1. Overview

This document describes the initial setup and configuration of the SAP Business Technology Platform (BTP) Trial environment.

The objective is to establish a cloud-based development environment for learning and experimenting with SAP technologies.

## 2. Environment Information

| Component | Configuration |
|---|---|
| Platform | SAP Business Technology Platform |
| Environment | Trial |
| Cloud Provider | Amazon Web Services (AWS) |
| Region | US East (Virginia) |
| Global Account | Trial account |
| Subaccount | trial |
| Organization | SAP-generated trial organization |
| Space | dev |

## 3. Prerequisites

The following requirements were needed to access the trial environment:

- SAP account.
- Valid email address.
- Telephone number for account registration.
- Web browser.
- Internet connection.

## 4. Setup Procedure

### 4.1. SAP Account Registration

Created a personal SAP account through the official SAP website.

The account provides access to SAP learning resources, developer tools and trial services.

### 4.2. SAP BTP Trial Activation

Requested access to the SAP Business Technology Platform Trial environment.

Completed the required personal information and accepted the trial terms and conditions.

### 4.3. Cloud Environment Provisioning

SAP automatically provisioned the initial cloud environment.

The following resources were successfully created:

- Global trial account.
- Trial subaccount.
- Development organization.
- Development space (`dev`).

### 4.4. Access to SAP BTP Trial

Successfully accessed the SAP BTP Trial welcome page.

The environment provides access to development tools, platform services and guided tutorials.
